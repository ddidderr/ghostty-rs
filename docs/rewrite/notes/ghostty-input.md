# ghostty-input port notes

## File mapping (ZIG/src/input -> crates/ghostty-input/src)
- input.zig -> lib.rs (re-exports); config.zig -> config.rs; keyboard.zig -> keyboard.rs
- key.zig -> key.rs (`Key` generated by macro with name()/from_name(); `KeyEvent<'a>` borrows utf8)
- key_mods.zig -> key_mods.rs (`Mods` is a plain bool struct + `int()/from_int()` u16 layout; `RemapSet` is an insertion-ordered Vec)
- keycodes.zig -> keycodes.rs (data table `RAW_ENTRIES`, `entries()` built lazily, Linux = xkb column)
- function_keys.zig -> function_keys.rs; key_encode.zig -> key_encode.rs (legacy + kitty)
- Binding.zig -> binding/{mod,action,set,tests}.rs; command.zig -> command.rs
- helpgen_actions.zig -> helpgen_actions.rs (`generate`/`generate_string`)
- mouse.zig, kitty.zig, paste.zig, Link.zig -> same-named modules
- Skipped: KeymapDarwin.zig, KeymapNoop.zig (macOS only / no-op).

## Naming deviations
- `Mods.super` -> `super_` (Rust keyword). Zig `final` -> `final_` in kitty::Entry.
- Binding Action doc comments are kept as `//` comments (indented lists would be doctests); text is exposed via `ActionKey::docs()` / `Action::docs()`.
- `Action::scoped(Scope)` returns `Option<&Action>`.
- paste: `encode(&[u8])` (const, may return MutableRequired) and `encode_mut(&mut [u8])` replace the comptime-typed Zig function.
- `Set.chain_parent` is a trigger path instead of raw pointers.
- Case folding: `char::to_lowercase` plus 3 special cases rather than uucode tables.
- `Value::format_entries` fixes a Zig bug (shared-buffer rewind corrupting sibling prefixes for chained leaves in sequences); test `set_format_entries_sequence_shares_prefix`.
- macOS-only branches (option-as-alt translation, ctrlOrSuper on Darwin) are compiled out; Linux behaviour only.

## Skipped tests
- 7 macOS-only key_encode tests (kitty/legacy with macos option/super text, `alt+x macos`, etc.) and Mods `translation macos-option-as-alt` (ported as a Linux identity test).
- RemapSet `formatEntry` tests use `format_entries()` (list of values) since the config formatter lives in ghostty-config.
- Zig `imguiKey` (cimgui) not ported; inspector deferred.
- `Link.oniRegex` not ported (regex engine chosen by consumer).
